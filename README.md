# Wokwi Simulation Projects

Welcome to the **Wokwi Simulation Projects** repository! This repository contains different experiments and their corresponding Wokwi simulation projects.

## 🚀 How to Run the Simulations

You can run any experiment's simulation directly in your browser without creating an account or logging in to Wokwi.

Follow these simple steps:

1. Open the respective experiment folder in this repository.
2. Open the experiment's `.txt` file.
3. Find and copy the Wokwi project URL provided inside the file.
4. Paste the URL into your web browser.
5. The Wokwi simulation will open directly.
6. Click the **Start Simulation** button to run the project.

**That's it!** No Wokwi login or account registration is required.

## 📌 Important Notes

- Each experiment has its own `.txt` file containing the corresponding Wokwi project link.
- Make sure you open the correct text file for the experiment you want to run.
- An active internet connection is required to access and run the simulations.
- You can explore the circuit connections, source code, and simulation results directly in Wokwi.
